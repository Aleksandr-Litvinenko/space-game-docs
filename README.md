# Космос — от человека до звездолёта

Браузерная космическая игра без установки. Вы начинаете пешком на поверхности планеты, находите спидбайк, выигрываете гонку, получаете корабль, облетаете звёздную систему и в конце получаете звездолёт, которым открыты все планеты.

Игра задумана как основа для MMO: прогресс, мир и присутствие игроков уже разделены на слои, которые потом можно вынести на сервер.

## Суть игры

| Стадия | Что делаете | Чем заканчивается |
|---|---|---|
| 1. Поверхность | Бегаете, прыгаете, стреляете, открываете ящики, ищете бластер и спидбайк | Садитесь на спидбайк |
| 2. Спидбайк | Летаете над долиной, проходите гонку через ворота, поднимаетесь на орбиту | Получаете корабль |
| 3. Корабль | Облетаете планеты системы, сканируете маяки, причаливаете к верфи | Получаете звездолёт |
| 4. Звездолёт | Облетаете все планеты, охотитесь на пиратов | Открытый мир |

На каждой стадии есть задания. Все задания стадии выполнены — открывается следующая стадия.

## Прокачка и добыча

- **Модули** выпадают из ящиков, дронов, пиратов, маяков и наград за гонку. У модуля есть слот (двигатель, корпус, оружие, навигация), редкость (обычный, редкий, эпический, легендарный) и уровень от 1 до 5.
- **Скрап** нужен для прокачки модулей. **Кредиты** — для будущих покупок.
- **Инвентарь и экипировка** хранятся отдельно для каждого транспорта. Модуль надевается на транспорт, старый уходит в инвентарь.
- **Скины** меняют цвет скафандра и окраску транспорта. Часть скинов открывается заданиями, часть выпадает из добычи.

Открыть инвентарь и гардероб — **Tab**.

## Управление

- **WASD** — движение (пешком) или курс (на технике).
- **Shift** — бег или форсаж. **Space** — прыжок или подъём.
- **Q / E** — боковой сдвиг на технике. **Ctrl** — вниз.
- **ЛКМ** — огонь. Первый клик захватывает курсор, мышь управляет взглядом.
- **E** — действие: подобрать, открыть ящик, сесть в транспорт, просканировать маяк, причалить.
- **M** — звёздная карта. **Tab** — инвентарь и гардероб.

## Управление на телефоне

На устройствах с сенсорным экраном появляются экранные кнопки:

- **Левый круг** — движение (или курс на технике).
- **Палец по правой части экрана** — взгляд. Тащите пальцем, чтобы повернуть камеру.
- **Кнопки справа:** «Огонь» (держать), «Вверх» (прыжок или подъём), «Бег» (или форсаж, держать), «Вниз», «Действие» (то же, что E), «Меню» (инвентарь, как Tab), «Карта» (как M).

Для удобства лучше держать телефон горизонтально. В книжной ориентации кнопки и HUD тоже работают, но экран тесный.

## Присутствие игроков

На поверхности видно других игроков: их модели, транспорт и имена. Состояние передаётся 10 раз в секунду через WebSocket. Если сервера нет, игра работает в офлайне: прогресс сохраняется локально, других игроков не видно.

## Запуск

Нужны Node.js 18+ и Python 3 для локального сервера. Нужен WebGL в браузере.

```bash
npm install          # пакет ws для сервера присутствия и puppeteer-core для проверок
npm run dev          # http://127.0.0.1:8000/index.html
npm run server       # сервер присутствия на ws://127.0.0.1:8787/ws (по желанию)
```

Для проверки с сервером откройте игру с параметром: `index.html?server=ws://127.0.0.1:8787/ws`.

Параметр `?debug=1` открывает игру и сервис присутствия в консоли как `window.game` и `window.presence`.

## Тесты

```bash
npm install          # в том числе puppeteer-core для браузерных проверок
npm test             # юнит-тесты чистой логики
npm run test:e2e     # стадии от старта до звездолёта в headless Chrome
npm run test:presence  # два клиента видят друг друга (нужен npm run server)
npm run test:touch   # сенсорное управление на эмуляции телефона
```

Юнит-тесты проверяют стадии, квесты, добычу, прокачку, сохранение, миграцию профиля, проверку сообщений сервера и преобразование джойстика. Браузерные проверки запускают Chrome: путь к нему задаётся переменной `CHROME_PATH`, адрес игры — `GAME_URL`.

```
  main.js             точка входа: загрузка моделей, интерфейс, игра, сеть
  three.js            единая точка входа для three.js (CDN)
  vendor/jsm/         аддоны three.js: загрузчик glTF, постобработка, небо, вода

  core/               чистая логика: профиль, квесты, добыча, прокачка, ввод, ассеты
  game/               мир: оркестратор, зоны, физика, бой, небо, модели, удалённые игроки
  game/zones/         зоны: поверхность (ground) и звёздная система (system)
  ui/                 HUD, панель инвентаря и гардероба, экранное управление (touch.js)
  net/                клиент сервера присутствия

tests/                юнит-тесты чистой логики
dev/                  страница проверки моделей (не входит в сборку)
scripts/              сборка и локальный сервер
assets/               модели, текстуры и спрайты (CC0, см. assets/CREDITS.md)
```

## Задел под MMO

- **Прогресс** сейчас лежит в `localStorage` и описан одним объектом профиля (`src/core/profile.js`) с версией и миграцией. Перенос на сервер — это замена хранилища, а не переписывание правил.
- **Квесты и добыча** работают на событиях. Игровой мир только сообщает, что произошло, решения принимает `applyEvent` и `grantRewards`. На сервере эти же функции смогут проверять прогресс.
- **Зоны** независимы: каждая зона строит свой мир и отдаёт события. Для MMO каждая зона станет отдельной комнатой сервера.
- **Сервер присутствия** пока только пересылает состояния. Следующий шаг — авторитетная симуляция: сервер сам проверяет попадания и выдачу добычи.
- **Случайность** детерминирована: генератор с seed (`src/core/rng.js`), поэтому результаты можно воспроизвести и проверить на сервере.
