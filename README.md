# MyMMO — космическая онлайн-игра

Браузерная MMO без установки. Вы создаёте героя (пол, раса, лицо, причёска, цвета), выходите в огромный общий мир, сражаетесь с монстрами, прокачиваетесь и открываете звёздную систему. Герой и его прогресс хранятся на сервере: войдите с любого устройства и продолжите там, где остановились.

## Что внутри

- **Герой.** Имя, пол, раса (четыре варианта с разным цветом кожи и ростом), одно из шести лиц, шесть причёсок с шестью цветами волос, цвет скафандра. Выбор сохраняется навсегда.
- **Мир.** Поверхность планеты Талит — карта 6 × 6 км с четырьмя биомами (пустыня, скалы, ледники, долины), горами, долинами и тремя городами: Старт, Пустошь и Ледник. Мир один на всех игроков и детерминирован: одинаковый рельеф у каждого клиента и на сервере.
- **Карта.** Большая карта (M) показывает биомы, города, трассу, лагеря монстров, ящики, игроков и вашу позицию. Мини-карта в углу показывает окрестности.
- **Бой.** Прицел в центре экрана. Цель под прицелом подсвечивается и подписывается: имя, уровень и здоровье. Попадания считает сервер по лучу.
- **Монстры.** Дроны и стражи в лагерях по всей карте. Уровень монстра растёт с удалённостью от старта. Монстры общие: их убивает один игрок — они возрождаются для всех.
- **Прокачка.** Опыт за монстров и квесты, уровни усиливают здоровье и урон. Модули (двигатель, корпус, оружие, навигация) выпадают из монстров, ящиков и наград, прокачиваются скрапом.
- **Стадии и квесты.** Пешком — найти бластер и спидбайк на площадке у Пустоши, затем гонка через восемь ворот на Трассе Ветра, выход на орбиту, облёт планет и маяков, верфь, звездолёт и пираты.
- **Космос.** Звёздная система с пятью планетами, верфью Ворна и патрулями пиратов. Корабль и звездолёт управляются тем же полётом.

## Управление

- **WASD** — движение (пешком) или курс (на технике).
- **Shift** — бег или форсаж. **Space** — прыжок или подъём. **Ctrl** — вниз.
- **Q / E** — боковой сдвиг на технике.
- **ЛКМ** — огонь. Первый клик захватывает курсор, мышь управляет взглядом.
- **E** — действие: подобрать бластер, открыть ящик, сесть на спидбайк, просканировать маяк, причалить.
- **Tab** — герой, инвентарь, гардероб, выход. **M** — карта мира.

На телефоне появляются экранные кнопки: джойстик слева, палец по правой части экрана — взгляд, кнопки справа: «Огонь», «Вверх», «Бег», «Вниз», «Действие», «Герой», «Карта». Для удобства держите телефон горизонтально.

## Аккаунты и сохранение

Регистрация — ник и пароль. Пароль хранится в виде хеша scrypt с солью, токен сессии — только как SHA-256 от себя. Токен сохраняется в браузере, поэтому повторный вход не требует пароля. Прогресс героя сохраняется на сервере через несколько секунд после изменений и при выходе из мира. Один аккаунт может быть в мире только с одного устройства: новый вход выбивает старый.

## Запуск локально

Нужны Node.js 18+ и Python 3 (для локального сервера статики). Нужен WebGL в браузере.

```bash
npm install          # пакет ws для сервера мира и puppeteer-core для проверок
npm run server       # сервер мира: ws://127.0.0.1:8788/ws, данные в ./data
npm run dev          # http://127.0.0.1:8000/index.html
```

Откройте страницу с параметром сервера: `index.html?server=ws://127.0.0.1:8788/ws` (по умолчанию игра ходит на тот же хост, по пути `/ws`).

Переменные сервера: `MYMMO_PORT` (по умолчанию 8788), `MYMMO_DATA_DIR` (где лежит `db.json`).

## Тесты

```bash
npm test             # юнит-тесты: правила мира, квесты, добыча, прокачка, сохранение, сервер
npm run test:e2e     # сквозной сценарий в headless Chrome: создание героя, мир, бой, сохранение,
                     # второй игрок (нужны сервер с MYMMO_DEV=1 и npm run dev)
```

Путь к Chrome задаётся переменной `CHROME_PATH`, адрес игры — `GAME_URL`, адрес сервера — `SERVER_URL`.

## Устройство

```
shared/              общий код клиента и сервера
  world.js           рельеф, биомы, города, трасса, лагеря, ящики, космос
  appearance.js      внешность героя и проверка создания
  content/           стадии, квесты, модули, транспорт, монстры
  core/              правила: квесты, добыча, прокачка, профиль, генератор случайных чисел
server/              сервер мира (Node.js + ws)
  index.js           HTTP и WebSocket, вход, регистрация, создание героя
  store.js           хранилище аккаунтов и сессий (атомарная запись в JSON)
  auth.js            пароли (scrypt), токены, ограничение попыток входа
  sim/world.js       зоны, герои, стрельба, взаимодействия, рассылка снимков 10 раз в секунду
  sim/monsters.js    поведение монстров и снаряды
  sim/progress.js    квесты, опыт, награды и смена стадий на сервере
src/                 клиент
  main.js            загрузка, вход, создание героя, мир
  net/client.js      соединение с сервером, переподключение
  game/              герой, мир по чанкам, сессия, полёт, превью редактора
  ui/                экраны входа и создания, HUD, прицел, карты, панель, сенсорное управление
tests/               юнит-тесты и сквозной сценарий в tests/e2e
```

Главное правило: сервер решает всё, что влияет на прогресс — бой, добычу, опыт, квесты, стадии. Клиент присылает намерения (двигаться, стрелять, нажать E) и рисует то, что пришло от сервера. Позиция проверяется на скорость и границы, так что телепорт на клиенте не сработает.

## Ограничения

- Мир один и не шардирован: все игроки в одной зоне. Для тысяч игроков понадобятся несколько серверов и база данных вместо JSON-файла.
- Хранилище — один JSON-файл с атомарной записью. Надёжно для одного сервера, но не для горизонтального масштабирования.
- Герой выглядит процедурно: тело из набора Kenney, голова, лицо и причёска собраны из примитивов. Для более качественных персонажей нужны отдельные модели.
- Звука нет. Бой и движение — без серверной физики: позиция приходит от клиента и проверяется на правдоподобие.
- Чат, группы и торговля между игроками пока не сделаны.
